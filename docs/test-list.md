# ToDo API テスト項目一覧（認証機能追加版）


## 1. 認証機能テスト
### 1.1 ユーザー登録 (/auth/register)
[ ] 有効なユーザー情報で正常に登録できること
[ ] 必須項目 (username, email, password) が欠けている場合に400エラーが返されること
[ ] ユーザー名が3文字未満の場合に400エラーが返されること
[ ] ユーザー名が50文字を超える場合に400エラーが返されること
[ ] メールアドレスが無効な形式の場合に400エラーが返されること
[ ] メールアドレスが最大長を超える場合に400エラーが返されること
[ ] パスワードが8文字未満の場合に400エラーが返されること
[ ] パスワードが複雑さ要件を満たさない場合に400エラーが返されること（実装されている場合）
[ ] 既に存在するユーザー名で登録しようとした場合に409エラーが返されること
[ ] 既に存在するメールアドレスで登録しようとした場合に409エラーが返されること
[ ] 登録成功時にユーザー情報が返されること（パスワードは含まれないこと）

### 1.2 ユーザーログイン (/auth/login)
[ ] 有効なユーザー名とパスワードで正常にログインできること
[ ] 有効なメールアドレスとパスワードで正常にログインできること
[ ] 存在しないユーザー名/メールアドレスでログインしようとした場合に401エラーが返されること
[ ] 誤ったパスワードでログインしようとした場合に401エラーが返されること
[ ] 必須項目 (username, password) が欠けている場合に400エラーが返されること
[ ] ログイン成功時にアクセストークンとリフレッシュトークンが返されること
[ ] レスポンスに適切なトークン有効期限情報 (expires_in) が含まれていること
[ ] 返されるトークンが有効で、保護されたリソースにアクセスできること

### 1.3 トークン更新 (/auth/refresh)
[ ] 有効なリフレッシュトークンで新しいアクセストークンが取得できること
[ ] 無効なリフレッシュトークンでエラーが返されること
[ ] 期限切れのリフレッシュトークンでエラーが返されること
[ ] リフレッシュトークンが指定されていない場合に400エラーが返されること
[ ] レスポンスに新しいアクセストークンとリフレッシュトークンが含まれていること
[ ] 更新されたアクセストークンで保護されたリソースにアクセスできること

### 1.4 ログアウト (/auth/logout)
[ ] 認証済みのユーザーが正常にログアウトできること
[ ] 認証なしでログアウトしようとした場合に401エラーが返されること
[ ] ログアウト後に古いトークンが無効化されること
[ ] 無効化されたトークンで保護されたリソースにアクセスできないこと

### 1.5 ユーザープロファイル取得 (/auth/profile)
[ ] 認証済みのユーザーが自分のプロファイル情報を取得できること
[ ] 認証なしでプロファイル情報を取得しようとした場合に401エラーが返されること
[ ] プロファイル情報にパスワードが含まれていないこと
[ ] プロファイル情報に登録時の必須フィールドとcreated_atが含まれていること
